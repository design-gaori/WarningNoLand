# 가로형 UI 점검 — 미흡해 보이는 부분 (STEP 2)

> 작성일: 2026-11-17 · 기준: Figma `땅없음 프레임 UI`의 1920×1080(16:9) 프레임
> 범위: **지적과 수정 제안만** 합니다. Figma와 디자인은 바꾸지 않았습니다.
> 근거: 프레임 메타데이터(노드 좌표·크기), 스크린샷. 좌표는 모두 프레임 기준 px입니다.
> 한계: 메타데이터에는 Figma의 constraints(고정·늘림 설정)가 나오지 않습니다. 그래서 "Figma 안에서 반응형으로 어떻게 설정했는지"는 확인하지 못했고, **배치 좌표만 보고** 판단했습니다.

중요도: 🔴 플레이·사용에 지장 · 🟠 화면 비율이 달라지면 깨질 가능성 · 🟡 다듬으면 좋은 부분
