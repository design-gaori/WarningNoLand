# G. 격자 규격과 스테이지 데이터

> 모든 배치·판정은 이 섹션의 격자를 기준으로 합니다. 화면 좌표(px)는 그리기에만 쓰고, 게임 규칙은 칸 좌표로만 처리합니다.

- [ ] **G-1. 격자 형태**
  - 작성:아이소메트릭 마름모 격자. 한 칸의 모양은 `0.기본틀.svg`의 마름모와 동일
- [ ] **G-2. 칸 비율과 크기**
  - 작성:`0.기본틀.svg` 기준 한 칸의 가로 약 198.6, 세로 약 124.0 (가로:세로 ≈ 1.6:1). 실제 화면 크기는 화면에 맞춰 비율 그대로 확대·축소
- [ ] **G-3. 칸 좌표 체계**
  - 작성:각 칸은 (열, 행) 정수 좌표로 표시. 화면 위치 변환은 다음 식을 사용
    - 화면 x = 원점 x + (열 − 행) × (칸 가로 ÷ 2)
    - 화면 y = 원점 y + (열 + 행) × (칸 세로 ÷ 2)
- [ ] **G-4. 이웃 칸의 정의**
  - 작성:변을 공유하는 4개 칸만 이웃. (열±1, 행) 과 (열, 행±1). 꼭짓점만 공유하는 칸은 이웃이 아님
- [ ] **G-5. 격자 크기**
  - 작성:스테이지마다 가로 × 세로 칸 수를 지정
- [ ] **G-6. 격자선 표시 여부**
  - 작성:미정, 레퍼런스 참조
- [ ] **G-7. 화면 크기 대응**
  - 작성:보드 전체를 하나의 단위로 비율 유지하며 확대·축소. 내부 상태는 칸 좌표로만 저장하므로 화면 크기가 바뀌어도 배치가 어긋나지 않음
- [ ] **G-8. 그리는 순서(깊이 정렬)**
  - 작성:화면 아래쪽(앞쪽)에 있는 칸의 오브젝트를 나중에 그림. 기준값은 (열 + 행), 같으면 열이 큰 쪽을 나중에
- [ ] **G-9. 안전콘 정의 형식**
  - 작성:안전콘 종류마다 아래 정보를 가짐
    - 이름(id)
    - 칸 패턴: 기준 칸 (0, 0)에서의 상대 좌표 목록. 예: 일자 2칸 = [(0,0), (1,0)]
    - 그림 파일 이름(피그마에서 전달)
- [ ] **G-10. 스테이지 정의 형식**
  - 작성:스테이지마다 아래 정보를 데이터로 분리해 관리 (스테이지 추가 시 데이터만 추가)
    - 격자 크기
    - 시작 땅 칸 좌표 목록
    - 도착 땅 칸 좌표 목록
    - 중간 섬 칸 좌표 목록(있을 경우, 섬별로 구분)
    - 사용할 안전콘 종류와 종류별 수량
- [ ] **G-11. 피그마 에셋 규칙**
  - 작성:
    - 모든 안전콘 그림은 기준 칸 마름모의 중심이 같은 위치에 오도록 맞춰서 내보냄
    - 여러 칸을 차지하는 땅 그래픽도 `0.기본틀.svg`와 같은 칸 크기를 기준으로 제작
    - 보관 영역용 축소 이미지는 별도 제작 또는 같은 이미지를 축소 사용(미정)

# 15. 테스트 체크리스트

## 15-1. 기본 조작 테스트

- [ ] 안전콘을 선택할 수 있다.
- [ ] 안전콘을 드래그할 수 있다.
- [ ] 드래그 중 놓일 칸 패턴이 그림자로 표시된다.
- [ ] 유효한 칸에 놓으면 칸에 정확히 스냅된다.
- [ ] 격자 밖, 이미 찬 칸, 땅 칸, 보관 영역에는 배치되지 않고 원래 위치로 돌아간다.
- [ ] 배치한 안전콘을 드래그해 다른 칸으로 옮길 수 있다.
- [ ] 배치한 안전콘을 탭·클릭하면 보관 영역으로 돌아간다.
- [ ] 아주 조금 움직이고 뗀 경우 드래그가 아닌 탭으로 처리된다.
- [ ] 안전콘 수량이 정확히 관리된다.
- [ ] 리셋 버튼이 모든 콘을 보관 영역으로 되돌린다.

## 15-2. 연결 판정 테스트

- [ ] 안전콘과 땅이 변을 공유하면 연결로 판정된다.
- [ ] 안전콘끼리 변을 공유하면 연결로 판정된다.
- [ ] 꼭짓점만 닿은 경우 연결되지 않는다.
- [ ] 시작 땅, 모든 중간 섬, 도착 땅이 이어지면 성공으로 판정된다.
- [ ] 중간 섬을 우회해 시작·도착만 이어진 경우 실패로 판정된다.
- [ ] 콘을 옮겨 연결이 끊어지면 판정이 갱신된다.
- [ ] 여러 경로가 있을 때 정해진 규칙대로 판정된다.
- [ ] 화면상 표시와 실제 판정이 일치한다.

## 15-3. 난이도 및 레벨 테스트

- [ ] 각 스테이지의 안전콘 종류와 수량이 데이터와 일치한다.
- [ ] 각 스테이지의 시작·도착·중간 섬 칸 위치가 데이터와 일치한다.
- [ ] 예시 해답으로 성공할 수 있다.
- [ ] 규칙을 위반한 배치가 허용되지 않는다.
- [ ] 정답이 여러 개라면 유효한 해법이 모두 인정된다.

## 15-4. 화면 및 안정성 테스트

- [ ] 화면 크기가 달라져도 배치된 콘이 같은 칸에 있다.
- [ ] 브라우저 확대·축소 시 조작이 정상 작동한다.
- [ ] 아이소메트릭 깊이 순서대로 앞쪽 콘이 뒤쪽 콘을 가린다.
- [ ] 드래그 도중 포인터가 화면 밖으로 나가도 상태가 꼬이지 않는다.
- [ ] 빠른 연속 조작과 멀티터치에도 오류가 발생하지 않는다.
- [ ] 새로고침 후 정의된 초기 상태로 시작한다.
- [ ] 개발자 콘솔에 해결되지 않은 오류가 없다.
