## 2. 구조

```
#app (창 크기. 모바일 세로면 90° 회전)
├─ .sky          하늘 그라디언트 — 창 전체 (단색 여백 없음)
├─ .scroller     세로 스크롤 (stage1만)
│   └─ .stage-plane (1920 × 2101 디자인 px, scale(u))
│       ├─ 구름 3
│       ├─ .board-layer (보드 원점 = 시작 땅 칸 중심)
│       │   └─ .board  scale(1.18875)  ← G-7: 보드 전체를 이 값 하나로 확대·축소
│       │       └─ 0.기본틀 칸 1개 (칸 (1,0), logic/grid의 cellToScreen으로 위치 계산)
│       └─ 흐린 점 9
├─ .hud-top      화면 고정, 위쪽 기준: RESTART, 보관 카드(넘치면 보관 영역만 스크롤)
├─ .ticker       화면 고정, 아래쪽 기준: 안내 띠
└─ .paper        맨 위 종이 질감 (color-dodge, 50%)
```

- 스크롤 길이: 도착 땅 아래 끝 + 48(Q31) + 안내 띠 48 = **2101 디자인 px**. 로직 데이터(stage-1.json)에서 계산합니다.
- 글꼴: Outfit 800·900, 나눔고딕 800. 빌드하면 나눔고딕이 글자 범위별 조각으로 나뉘어, 화면에 나온 글자가 든 조각만 내려받습니다.

- 가로 스크롤은 어떤 크기에서도 생기지 않았습니다.
- 맨 아래까지 스크롤하면 구름 3·흐린 점이 보이고, RESTART·카드·안내 띠는 제자리에 있습니다 ✅
- ⚠️ 브라우저 미리보기의 스크린샷이 자주 시간 초과되었습니다. 그래서 **숫자(요소 위치) 측정을 기준으로 판정**했고, 스크린샷은 눈으로 보조 확인했습니다.
  - 원인 후보: 카드의 `backdrop-filter`, 전체 화면 `mix-blend-mode`, SVG 흐림 필터의 렌더링 부담
  - **실제 아이맥·휴대폰에서 부드럽게 그려지는지는 확인하지 못했습니다.**
- 확인하지 못한 것: 실제 기기, Safari, 회전 상태에서 손가락 스크롤 방향

## 4. Figma와 다른 부분

| # | 다른 점 | 이유 |
|---|---|---|
| D1 | 보관 카드가 겹치지 않고 **8px 간격**으로 펼쳐져 있음 | Q36. 펼침 모션(−200 → 8)은 아직 없음 |
| D2 | 카드에 **콘 그림 없음**, 수량은 모두 `5/5` | STEP 6 범위(콘 없음). Figma의 3/5·4/5는 임시 값(Q14) |
| D3 | 보드에 흰 격자선 없이 **0.기본틀 칸 1개만**(검은 선) | STEP 6 지시. 시작·도착 땅 콘도 아직 없음 |
| D4 | 안내 띠 글꼴이 **나눔고딕 ExtraBold**(Figma: Inter Bold), **정적** | Q4, 이번 답변(모션은 나중) |
| D5 | 종이 질감·하늘 그라디언트가 **창에 고정**되어 스크롤해도 움직이지 않음(Figma는 1080 프레임 안 그림) | 스크롤 화면에서 질감이 끊기지 않게 함(가정) |
| D6 | 아이맥 브라우저 창(주소창 있음)에서 **세 번째 카드가 보관 영역 스크롤 아래로 일부 숨음** | 배율 = 너비 ÷ 1920 + 보관 영역 스크롤(Q37) 결정에 따른 결과 |
| D7 | 작은 화면(휴대폰)에서 글자가 Figma 비율보다 큼 | 최소 글자 크기(가정 G1) |
| D8 | 스크롤바가 보이지 않음(휠·트랙패드·손가락으로 스크롤) | 디자인에 스크롤바가 없어서 숨김(가정) |
| D9 | 오른쪽 아래 구름이 카드에 일부 가려짐 | Figma와 같음(의도된 가림, 가로형 답변 7) |
| D10 | Frame 22 안의 점(Ellipse 12)은 같은 크기의 `dot-27` 그림으로 대신함 | Figma에서 이 점만 따로 내보내지지 않음(모양 같다고 가정) |
| D11 | RESTART는 버튼 모양만 있고 동작 없음 | STEP 6 범위(동작 없음) |
| D12 | 휴대폰 노치·둥근 모서리 여백(safe-area)을 처리하지 않음 | 가로형 점검 A4는 아직 결정되지 않음 |

### 가정 (확인 필요)

- **회전은 터치 기기(`pointer: coarse`)에서만** 합니다. 데스크톱 창을 세로로 길게 줄여도 회전하지 않습니다.
- 회전 방향은 **시계 방향 90°**입니다. 그래서 휴대폰을 **왼쪽(반시계)으로 눕혀** 들어야 바르게 보입니다.
