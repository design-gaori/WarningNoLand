**15-1 기본 조작**
- [ ] 보관 카드의 콘 그림을 누르고 끌면, 콘이 보드 크기로 커져 손가락·마우스를 따라온다
- [ ] 끄는 동안 콘이 놓일 격자 칸이 **흰색으로 채워지고** 콘을 따라 움직인다
- [ ] 놓으면 콘이 칸에 딱 맞게 붙는다(칸 아래와 콘 아래가 맞닿음)
- [ ] 격자 밖·보관함 위에 놓으면 보관함으로, 땅·다른 콘 위에 놓으면 원래 자리로 돌아간다
- [ ] 놓인 콘을 끌어 다른 칸으로 옮길 수 있다
- [ ] 놓인 콘을 살짝 클릭·탭하면 보관함으로 돌아간다(카드 수량 +1)
- [ ] 아주 조금(5px 미만) 움직이고 떼면 탭으로 처리된다
- [ ] RESTART를 누르면 모든 콘이 보관함으로 돌아간다

**15-4 화면·안정성**
- [ ] 콘을 놓은 뒤 창 크기를 바꿔도 같은 칸에 있다
- [ ] 브라우저 확대·축소(⌘+/⌘−) 후에도 끌어 놓기가 정확하다
- [ ] 앞쪽 콘이 뒤쪽 콘을 가린다(`?demo=1`로 확인)
- [ ] 끌면서 마우스를 브라우저 창 밖으로 나갔다 들어와도 이상해지지 않는다
- [ ] 콘을 끌어 화면 **아래쪽(안내 띠 근처)**에 대고 있으면 화면이 아래로 스크롤되고, **위쪽 끝**에서는 위로 스크롤된다
- [ ] 빠르게 여러 번 잡고 놓거나, 두 손가락으로 동시에 잡아도 꼬이지 않는다(휴대폰)
- [ ] 휴대폰: 콘 위에서 끌면 드래그, 빈 곳에서 끌면 화면 스크롤
- [ ] 새로 고침하면 처음 상태(5/5·5/5·5/5, 빈 보드)로 돌아온다
- [ ] 개발자 콘솔에 빨간 오류가 없다
