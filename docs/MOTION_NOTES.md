### 효과음 상세 (C6)

- `src/audio/sound.ts`의 `playEffect()`: 효과음을 4개 미리 준비해 두고 돌려 쓴다. 빠르게 연달아 놓아도 소리가 끊기지 않는다. 음량 `SOUND.effectVolume` 0.8.

- 안 나는 때: 보관함 회수(탭·보관함으로 끌기), 땅·다른 콘 위라서 원래 자리로 돌아갈 때, 격자 밖에 놓아 보관함으로 돌아갈 때

## 5. BACK·RESTART 마우스 올림 색 (2026-11-18)

- 기준: Figma `hover` 프레임(15:2) — 모양은 같고 그라디언트만 진하게 `#F95200 → #FF6C1B(52%) → #FF9131`
  (기본: `#FF7531 → #FF833E → #FFAE67`). 그림은 `assets/svg/figma/button-hover.svg`로 내려받음.
- 적용 버튼: 게임 화면 BACK·RESTART, 스테이지 선택 BACK, 도감 BACK
- 방식: 진한 그림을 겹쳐 두고 마우스를 올리면 0.15초 동안 서서히 보이게(`MOTION.buttonHover.duration`).
  마우스가 있는 기기에서만 동작(`@media (hover: hover)`) — 터치 기기에서 눌린 뒤 색이 남지 않게.
- 함께 바뀐 점(영향 범위): 버튼이 **마름모 모양 안에서만** 반응하도록 함(이전에는 사각형 모서리 빈 곳도 눌렸음). 버튼 안쪽은 그대로 눌림.
- 확인: 실제 마우스를 RESTART에 올리면 hover 그림 불투명도 1(BACK은 0 그대로), RESTART 클릭 → 보드 비워짐, 게임 BACK 클릭 → 스테이지 선택.
